# Manohar Kalyaan — Interactive Portfolio

Personal portfolio website focused on cybersecurity, data science, and software development.

## Run locally
Open `index.html` in a browser.

## Deploy with GitHub Pages
1. Create a GitHub repository.
2. Upload all files from this folder to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**.
4. Choose the `main` branch and `/ (root)`.
5. Save and open the GitHub Pages URL shown by GitHub.

No build step is required.
